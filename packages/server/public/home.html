How it works

Send messages. Ask questions. That's it.

No schema to design, no embeddings to tune, no prompts to write.

  1. [ 01 ] send

    Send the conversation

    One call per turn from the SDK, or a plugin does it for you.

    await session.addMessages(
  alice.message("Moved to Utrecht")
);
  2. [ 02 ] learn

    Recall learns in the background

    Facts with dates and sources. When something changes, the old fact is closed.

    Lives in Amsterdam
    Lives in Utrecht since Sep
  3. [ 03 ] ask

    Ask, or inject

    Ask in plain language, or put ready-made context into your next prompt.

    Where does Alice live?
    Utrecht, since SeptemberM2.

What Recall keeps

  • Factswith when they held and the messages they came from
  • Changes over timereplaced facts are closed and kept as history
  • Preferenceslikes, dislikes and how they want things done
  • People and relationshipswhat each person knows about the others
  • Sessions and scopesa summary per conversation, recall per project or account
Night shift

Then Recall sleeps on it.

When a conversation goes quiet, Recall goes back over what it learned about each person.

  • Merges duplicateswhat was said twice is kept once
  • Closes facts that changedincluding changes it missed the first time
  • Draws conclusionsacross conversations, each with its sources
  • Rewrites the profile cardas the person changes
  • Included in the priceat most three small model calls a pass

Why Recall

The hard parts of memory, already done.

  • Says when it doesn't know

    Every answer comes with its sources and a confidence. When memory holds nothing, it says so instead of guessing.

  • See what it knows

    A dashboard to browse each person's facts, current and replaced, and to try questions before your users do.

  • Forget on request

    Erase a person and what was learned about them with one call, or delete a session or a single fact.

  • Private, in the EU

    Stored in Frankfurt, never used for training. Answers come from US model providers chosen because they don't keep prompts; each one is named in our privacy policy.

  • Keys you can scope

    Limit an API key to one workspace, person or session, and revoke it from the dashboard at any time.

  • Spend you control

    Prepaid credit with a monthly cap and optional auto top-up, and usage per day in the dashboard.

FAQ

Questions, answered.

How is Recall different from a vector database?

A vector store returns similar text. Recall reasons over conversations: it extracts facts about each person, keeps when they were true and where they came from, resolves contradictions, and answers questions in plain language with citations.

Is there an SDK?

Yes, for TypeScript and Python: npm install @recall-memory/sdk or pip install recall-mem (imported as recall_memory). Both create nothing until you use it, make writes safe to retry, and turn memory into OpenAI or Anthropic messages. SDK docs.

I already use another memory API. Do I have to rewrite my code?

Probably not. Recall implements the v3 memory REST API, so code written for it works once you point its base URL at Recall and use a Recall key. How to switch.

Where is my data stored?

In the EU: the API runs in Frankfurt and the database is in Frankfurt, and your data is never used to train models. To learn and answer, Recall sends text to AI models that run in the US (Anthropic and OpenAI, through OpenRouter), and asks for providers that do not collect it; the privacy policy lists every party involved. Each account is isolated, API keys are stored as hashes, and you can export or permanently erase an account from the dashboard.

Which models does Recall use?

A fast model builds memory in the background and a stronger one answers. We choose both by eval score and swap them when something scores higher; current results are on the evals page. Today Recall Loom builds memory (and answers at the minimal level) and Recall Lumen answers. Details.

Can I self-host?

Yes. The server is source-available under the Functional Source License, so you can run it for your own products and company with your own model provider keys; it may not be offered to others as a competing memory service. The hosted service in the EU is the easiest path, with nothing to operate. The code is on GitHub, and the docs show how to run it with Docker.

What happens when my credit runs out?

Messages are always accepted, so you never lose data. Learning and chat pause with a clear error until you top up, or turn on auto top-up with a monthly cap.
