Guides / Frameworks

n8n

For AI agents built in n8n. The community package @recall-memory/n8n-nodes-recall adds two nodes: Recall Memory, a memory for the AI Agent that remembers each user across conversations, and Recall, which asks, searches and updates what Recall knows, on its own or as a tool the agent calls.

What you get

NodeWhat it does
Recall MemoryPlugs into the AI Agent's Memory input, like n8n's own memory nodes. Each run gets what Recall knows about the user from every earlier conversation (a short profile and the facts most relevant to the incoming message), then this conversation within a token budget: a summary of older turns and the latest messages. After the agent answers, the turn is stored and Recall keeps learning.
RecallAsk Memory, Remember a Fact, Search Memory, Get Profile and Add Message. Connect it to the AI Agent's Tool input and the agent decides when to use it ("remember that I'm vegetarian"), or use it in any workflow, for example to store support tickets so Recall learns from them.

The difference with a chat-history memory: n8n's Simple, Postgres and Redis memories keep the last messages of one conversation. Recall keeps what it learned about the person, so a user who comes back next week in a new conversation is still known, and every fact links to the message it came from.

Build it

  1. Install the nodes. In a self-hosted n8n, open Settings → Community Nodes → Install and enter @recall-memory/n8n-nodes-recall.
  2. Add the credential. Create an API key at app.recallmem.dev/keys ($5 of free credit, no card) and add a Recall API credential with it. Workspace: one name per app (for example support-bot), so two apps never share what they know about a person. Leave the base URL as it is unless you run your own Recall server.
  3. Connect the memory. Add a Recall Memory node to your AI Agent's Memory input. With a Chat Trigger the defaults work as they are.
  4. Say who the user is. Set User ID to something stable for the person: an email address, a customer ID, or the sender's user ID for Telegram or WhatsApp. With the default (the session) Recall only remembers within one conversation.
  5. Optionally, add the tool. Add a Recall node to the agent's Tool input with the operation Remember a Fact, and the agent can save what the user asks it to remember.

A Telegram bot, for example: Telegram Trigger → AI Agent with your chat model, Recall Memory (Session ID {{ $json.message.chat.id }}, User ID {{ $json.message.from.id }}) and, as a tool, Recall → Remember a Fact with the same User ID.

Settings that matter

FieldUse
User IDWho the agent talks to. Letters, digits, _ and - are kept as they are. Any other ID is cleaned up and given a short code made from the original, so jane@example.com is stored as jane_example_com_ followed by 10 characters, and two different IDs never share a memory. Use the same ID in the Recall node.
Memory PlacementSystem Message (default) works with OpenAI, Mistral, Groq and Ollama models. Choose User Message with Anthropic and Gemini models, which accept a system message only as the first message.
Context TokensBudget for this conversation's history (default 2,000). Older turns are summarised, not cut off.
Relevant ToRecall brings the facts most relevant to this text; the default is the incoming chat message.
Agent IDThe agent's ID in Recall (default assistant). Its replies are kept as context, never as facts about anyone.

n8n Cloud

Community nodes installed from npm run on self-hosted n8n. n8n Cloud shows only community nodes n8n has verified; the package is built to n8n's verification rules (no dependencies, n8n's lint rules) and will appear there once n8n has reviewed it. Until then, Cloud users can call the REST API with the HTTP Request node.

Cost and speed

Reading memory at the start of a run is a context call: included in the price and well under a second. Storing the turn is one request after the agent answers. Recall learns from the user's messages in the background, and that is what you pay for: $1.75 per million message tokens. Ask Memory is a question, a model call of a few seconds, from $0.0008. Prices are on the pricing page and worked examples in Cost and speed.

Privacy and forgetting

Everything a user writes to an agent with Recall Memory is stored and learned from. Say so in your privacy notice, and keep passwords and card numbers out of chats. Clearing the memory (n8n's Chat Memory Manager) deletes the session from Recall; to forget a person entirely, delete them in the dashboard or through the API, as Privacy, consent and forgetting describes.
