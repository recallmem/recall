One memory for ChatGPT and Claude

Every assistant keeps its own memory, and none of them share it. Tell ChatGPT you moved, and Claude still thinks you live in the old place. Recall is one memory that all your AI apps read and write, with the date of each fact and the message it came from.

Connect your apps

Each app signs in to Recall itself: you paste one URL, sign in with your email and approve. There is no API key to copy.

https://api.recallmem.dev/mcp
  • Claude (web, desktop and mobile): Settings, Connectors, Add custom connector. Name it Recall, paste the URL, leave the OAuth fields empty, then Connect. In a chat, switch Recall on in the tools menu.
  • ChatGPT: turn on developer mode (Settings, Apps & Connectors, Advanced settings), then create a connector with the same URL and OAuth, and sign in when ChatGPT asks.
  • Claude Code: claude mcp add --transport http recall https://api.recallmem.dev/mcp, then run /mcp and choose Authenticate. For memory in every session, use the Claude Code plugin.
  • Cursor, VS Code and other MCP apps: add a remote MCP server with the same URL; the app finds the sign-in itself.

What it does

  • Saves what lasts: preferences, plans, people, decisions. Say "remember that…", or let the app save lasting facts on its own (you choose when you connect it).
  • Answers from memory with sources: ask "what did I decide about the venue?" and get the current answer, not last month's.
  • Keeps history: when something changes, the old fact is closed with a date instead of being overwritten.
  • Says when it doesn't know, instead of guessing.

You stay in control

  • Browse everything it remembers on the dashboard, correct it, or ask any app to forget a fact.
  • See which apps are connected and revoke one in a click; it is signed out within seconds.
  • Stored in the EU (Frankfurt), never used to train models. Erase a person entirely when you need to.

What it costs

New accounts get $5 of credit, with no subscription. Searching memory and adding it to a conversation are included. A question answered from memory costs $0.005 at the default level, and saving a fact a fraction of a cent.
