Recall and Zep compared

Last updated: 13 October 2026

Zep builds a temporal knowledge graph for each user from chat messages and business data, and returns a block of relevant context for your agent's prompt. It is a hosted service; its graph engine, Graphiti, is open source.

Every fact about Zep on this page is from Zep's own public pages, linked under Sources, as we read them on 13 October 2026. What we could not check there is left out. Tell us at support@recallmem.dev if something has changed.

Pricing

Zep charges credits for what you send: an episode (a chat message, a JSON payload or a block of text) uses 1 credit per 350 bytes or part of it. Retrieval, storage, threads, users and graph storage use none.3 Recall charges per message token learned and per question; context and search are included.

Hosting and licences

Hosted. Zep Cloud, with options on Enterprise to bring your own encryption keys or to run Zep inside your own cloud account. Zep states it is SOC 2 Type II certified and offers HIPAA BAAs on Enterprise.3 Recall runs a hosted service with data stored in Frankfurt (EU).

Self-hosted. Zep stopped maintaining Zep Community Edition in April 2025. Graphiti, Zep's temporal knowledge graph framework, is open source under Apache 2.0.4 Recall's whole server can be self-hosted, source-available under the Functional Source License (each version Apache 2.0 after two years).

API

Zep has its own API: each user has a graph and a thread history; messages added to a thread are ingested into the user's graph; facts are edges, and a fact that a newer one invalidates keeps the time it became invalid.1 It is not compatible with Recall's API. A Zep user maps to a Recall peer and a thread to a session. To move, send the conversations you kept to Recall's messages endpoint and Recall learns from them.

When to choose Zep

  • You need a knowledge graph of entities and relationships, with your own entity and edge types, built from business data as well as chat.
  • You need compliance paperwork or deployment options that Recall does not offer: SOC 2 Type II, a HIPAA BAA, your own encryption keys, or running in your own cloud (Enterprise).
  • You want to pay per message sent, with retrieval free.
  • You want a Go SDK.

When Recall fits better

  • You want Recall to write the answer, with citations, a confidence and an explicit "I don't know", in one model call.
  • You want to self-host the whole memory service, not only a graph framework.
  • You want pay as you go without a monthly plan, data stored in the EU, or the v3 memory API that Honcho's clients also speak.
