Recall and Mem0 compared

Last updated: 13 October 2026

Mem0 is a memory layer for AI apps. It distills conversations into memories and returns the most relevant ones when your agent asks. It comes as a managed platform and as an Apache-2.0 library and server.

Every fact about Mem0 on this page is from Mem0's own public pages, linked under Sources, as we read them on 13 October 2026. What we could not check there is left out. Tell us at support@recallmem.dev if something has changed.

Pricing

The two price different things. Mem0 sells monthly plans with an allowance of add requests (storing a new memory) and retrieval requests (fetching memories for a context).3 Recall has no monthly fee: it charges per message token learned and per question, and context and search are included.

Recall: learning $1.75 per 1M message tokens (a message counts as at least 50 tokens), a question $0.0008 at minimal, $0.005 at low (the default) and up to $0.25 at max; context, search and the night shift included; $5 of credit to start. A retrieval in Mem0 returns memories for your own model to read; the closest Recall calls, context and search, are included in the price, and a Recall question also writes the answer. Which costs less depends on how long your messages are and how often you ask.

Hosting and licences

Hosted. Mem0 runs the Mem0 Platform; on-prem deployment of it is part of Enterprise.3 Recall runs a hosted service with data stored in Frankfurt (EU).

Self-hosted. Mem0's library and self-hosted server are Apache 2.0, an OSI licence; you bring the vector database, the LLM and the hosting.23 Recall's server is source-available under the Functional Source License (each version Apache 2.0 after two years) and needs only Postgres with pgvector, or an embedded database, plus your model provider keys.

API

Mem0 has its own API: you add memories, search them and update them, scoped by user, agent, app and run.1 It is not compatible with Recall's API, so moving means changing your calls. A Mem0 user maps to a Recall peer and a run or conversation to a session. If you kept the conversations, send them to Recall's messages endpoint and Recall learns from them; memories you want kept word for word can go in as conclusions (POST …/conclusions).

When to choose Mem0

  • You want an Apache-2.0 library that runs inside your own process, or a fully open-source server.
  • A free monthly allowance fits your app: Mem0's Hobby plan includes 10,000 add requests and 1,000 retrieval requests a month.
  • You prefer a fixed monthly price by request count to paying per token and per question.
  • You want graph memory with entity linking (Pro and up), or you weigh Mem0's higher published LongMemEval figure, measured on its own harness and judge.

When Recall fits better

  • You want Recall to write the answer, with citations, a confidence and an explicit "I don't know", in one model call.
  • You want facts with dates: when a fact stops being true it is closed, and the history stays visible.
  • You want no monthly fee, data stored in the EU, or the v3 memory API that Honcho's clients also speak.
