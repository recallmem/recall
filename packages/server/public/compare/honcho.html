Recall and Honcho compared

Last updated: 13 October 2026

Honcho, by Plastic Labs, is a memory API for agents. Recall implements Honcho's v3 REST API, so the two take the same requests and code moves between them by changing the base URL and the key.

Every fact about Honcho on this page is from Plastic Labs' own public pages, linked under Sources, as we read them on 13 October 2026. What we could not check there is left out. Tell us at support@recallmem.dev if something has changed.

Pricing

Both price learning by the token and questions by reasoning level, with the same five levels, and both include context. Recall bills each message as at least 50 tokens.

A worked example. A support assistant that learns from 1,000,000 message tokens a month and asks 500 questions at low pays $4.25 on Recall ($1.75 + $2.50) and $7.00 on Honcho at its list prices ($2.00 + $5.00), if Honcho counts the same tokens. Honcho's monthly $5 of credit, with a card on file, covers most of that bill; Recall's $5 is given once.

Hosting and licences

Hosted. Both run a hosted service. Recall stores data in Frankfurt (EU); its models run through providers in the United States (see the data processing agreement).

Self-hosted. Honcho's server is open source under the AGPL-3.0, an OSI licence.2 Recall's server is source-available under the Functional Source License: you may run it in production for your own products and change it, but not offer it to others as a competing memory service, and each version becomes Apache 2.0 two years after release. Honcho needs Postgres with pgvector and refuses to start without an LLM provider configured.3 Recall runs as one process with Postgres and pgvector or an embedded database, and without a provider key it runs on an offline mock model, which is enough to try the API.

API

Recall implements Honcho's v3 REST API: the same paths, bodies, errors, filters and pagination, and Honcho's MCP tool names. We ran Honcho's own published clients, honcho-ai and @honcho-ai/sdk version 2.5.1, against Recall with only the base URL and the API key changed, and a whole app worked; the TypeScript run is a test in Recall's repository that runs on every change. The differences that matter (reads that do not create, different models, bounded peer cards, retried webhooks, self-hosting settings) are in Switch from Honcho.

When to choose Honcho

  • You want an open-source licence. Honcho's server is AGPL-3.0; Recall's server is source-available and may not be offered to others as a competing memory service.
  • You need results at very long histories. Honcho publishes BEAM figures at 1M and 10M tokens; Recall has not run those yet.
  • Your usage is small and steady. Honcho's $5 of credit every month, with a card on file, can cover it; Recall's free credit is given once.
  • You are a startup that qualifies for Honcho's $1,000 credit programme, or you want Plastic Labs' own reasoning model.

When Recall fits better

  • You want lower list prices: Recall charges less for learning ($1.75 against $2.00 per 1M tokens) and for a question at every level.
  • You want answers you can check: chat can return citations, a confidence, and an explicit "I don't know", and facts carry the dates they were true.
  • You want your data stored in the EU.
  • Either way, trying the other is a change of base URL and key.
