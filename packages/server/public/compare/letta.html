Recall and Letta compared

Last updated: 13 October 2026

Letta (formerly MemGPT) is a platform for stateful agents: the agent itself runs on Letta and keeps and edits its own memory. Recall is a memory service that an agent you already have calls. They solve different parts of the problem, so this page is mostly about which one fits.

Every fact about Letta on this page is from Letta's own public pages, linked under Sources, as we read them on 13 October 2026. What we could not check there is left out. Tell us at support@recallmem.dev if something has changed.

Pricing

Letta prices an agent platform: plans, active agents, tool execution time and model usage.3 Recall prices a memory service: $1.75 per 1M message tokens learned and $0.0008 to $0.25 per question, with context and search included, no ongoing storage fee (a message stored without being learned from, or a fact you add yourself, costs $0.25 per 1M tokens, once) and no monthly fee. The two do not compare line by line; with Recall your agent and its model run, and are paid for, wherever you run them today.

Hosting and licences

Hosted. Letta Cloud runs your agents. Recall runs only the memory, with data stored in Frankfurt (EU); your agent runs wherever it runs now.

Self-hosted. Letta's local runtime and App Server are Apache 2.0; self-hosted agents are not reachable through Letta's web app and are not backed up automatically.45 Recall's server is source-available under the Functional Source License (each version Apache 2.0 after two years).

API

In Letta you create an agent, then send it messages and stream its replies.6 Its memory lives in MemFS, a git-backed memory filesystem the agent inspects and edits, and a background "dreaming" pass consolidates it.8 Recall has no agent runtime: your agent sends it conversations, reads context for its prompt and asks it questions. Moving from one to the other is a change of architecture, not of settings.

When to choose Letta

  • You want a platform that runs the agent itself, with its state, tools and memory managed for you.
  • You want an agent that edits its own memory, or you build on Letta Code.
  • You want an Apache-2.0 runtime you can host.

When Recall fits better

  • You already have an agent, on any framework or model, and want it to remember the people it talks to.
  • Many people, many conversations: Recall keeps a separate, dated record per person and answers questions about them with sources.
  • You want memory in Claude, ChatGPT, Cursor, Claude Code or Codex through MCP or a plugin, without moving your agent.
