# Recall

> Recall is long-term memory for AI agents: a hosted API in the EU (Frankfurt). Send it the conversations your agent has with people. Recall keeps a dated, cited record of each person, retires facts that stop being true, and answers questions about them in a single model call. It implements the v3 memory REST API and has TypeScript and Python SDKs, an MCP server, and plugins for Claude Code and Codex.

Recall is run by Smidt Beheer, the Netherlands (KvK 99124254). Data is stored in Frankfurt and never used to train models. Contact: support@recallmem.dev.

## Get started

- API base URL: https://api.recallmem.dev (send `Authorization: Bearer $RECALL_API_KEY`)
- API key: sign in with your email at https://app.recallmem.dev/keys; new accounts get {{signup_credit}} of free credit, no card needed
- TypeScript SDK: `npm install @recall-memory/sdk`
- Python SDK: `pip install recall-mem` (import `recall_memory`)
- MCP server: https://api.recallmem.dev/mcp
- Claude Code plugin: `/plugin marketplace add RedSix6/recall-plugin`, then `/plugin install recall-memory@recall`
- Source code: {{repo_url}} (the server is source-available under the FSL and can be self-hosted; SDKs and integrations are MIT)
